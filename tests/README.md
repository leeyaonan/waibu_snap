# 自动化测试

使用 Qt Test + CTest，Python 3 仅运行测量计算单测（标准库）。构建后执行成对的 `test-project` 脚本。

`startup_smoke` 使用 `QT_QPA_PLATFORM=offscreen`，验证 QWidget / 菜单动作与生命周期；无头环境不显示系统托盘，也不注册真实热键或申请屏幕录制权限。复制测试注入 `OverlayActions::copyImage`，仅验证动作次数、物理像素 / DPR 及终态，不读写或断言系统剪贴板。面板测试注入 `chooseSavePath`，路径导出调用真实 PNG 编码与原子提交，不能代替原生面板实机验收。

所有设置用例使用 `QTemporaryDir` 下 INI；实际应用子进程显式传入 `--settings-file` 临时路径。`hotkey_settings` 使用热键替身验证共享协调顺序，窗口吸附用例注入局部逻辑窗口矩形，不能替代 Carbon 硬件按键或 CGWindowList 像素边界验收。高亮与吸附输出测试回读冻结帧的已知彩色像素，显示层不参与输出。

实际应用执行 `--smoke-test` 时检查驻留策略、菜单结构、临时窗口显示及关闭、事件循环持续运行，再触发「退出」动作；退出断言有进程超时与状态检查。`--smoke-test` 仅 `BUILD_TESTING=ON` 可用，不能把关闭最后窗口即退出当作托盘应用行为。普通截图不因松开而结束；NF01 受控注入仍可交互后自动取消（码 2）。

## 人工核对清单（待用户真机操作）

- 以下启动均传入 `--settings-file <临时路径>`，使用同一临时 INI 验证改键重启保留，避免污染真实配置域。
- macOS 27 托盘图标反复单击 / 双击、打开和关闭菜单，确认不崩溃；进入「设置…」、取消和保存，再从菜单栏「退出」。合成 NSEvent 测试只验证方法绕行，无法模拟真实 AppKit 手势与菜单追踪链路。
- 用 `run-app.sh --test-mode --test-count 2`（临时设置和日志）实际捕获，确认两条注入会话均为码 2，帧尺寸非零且有可见代理 / 可交互终点；Ctrl+C 只结束脚本，普通实例继续驻留，随后从菜单栏退出。
- 普通实例经 `open` 启动后，再执行 `run-app.sh` 应提示已有实例；再用 `open -n` 启动普通实例，确认第二个进程正常退出且托盘仅一份。换一份 `--settings-file` 仍不能绕过锁。退出首个实例后可重新启动；受控和冒烟路径不受锁影响。此项保留人工核对：真实托盘、LaunchServices 与跨进程锁生命周期需要可见桌面和真实配置域，多实例自动测试易干扰日常热键 / 运行实例，隔离成本较高。
- 撤销 / 允许屏幕录制并按系统要求重启，从访达 / `open` 重试；未授权及捕获被拒时应提示 macOS 27 的启动方式。应用已授权时，终端直接执行仍可能被判未授权。注册 F1 失败且无旧绑定时应说明「当前未启用截图快捷键，可使用托盘入口」，不能说旧键已保留。
- 普通浏览器、文件管理器、编辑器悬停高亮：包含标题栏、不含阴影；只在空闲态显示，手动拖选或已有选区时消失，清除后恢复。
- 单击吸附后出现工具栏，可移动、四边 / 四角调整，外部拖动替换；单击不会直接复制 / 保存。越屏窗口只取会话所在屏内部分，多显示器仅在当前屏吸附。
- 重叠窗口命中最前层，吸附后的 PNG 保持冻结画面中的可见遮挡像素；以像素网格核对选区与输出边界，误差口径沿用 M08。
- 改为 ⌘⇧2 后立即响应新键、F1 失效，退出重启保留；设置打开期间热键不开始截图，截图期间「设置…」置灰、结束后恢复；取消或 Esc 不保存。
- 准备被其他应用占用的冲突键：保存失败后对话框保持打开，旧键仍响应、文件不变，可换键重试。⌘⇧3 / 4 / 5 应提示可能被系统占用；裸字母、裸数字、仅 Shift、空键被拒绝。
- 退出后热键注册与选区均释放；Fn / 地球键模式不被应用修改。Carbon 返回成功不等于真实键盘一定发送该键，需在其他应用前台逐项按键核对。
- macOS 从菜单栏或 F1 截图：移动、八个边角、反向夹停、屏边夹取、尺寸提示与工具栏位置。
- 点击「复制」后在支持图片的系统应用与日常沟通应用粘贴，核对内容与物理像素尺寸，确认会话结束。Qt 本地接受检查不能证明外部应用已正确粘贴。
- 保存 PNG 后用系统图片查看器打开，像素尺寸与工具栏提示一致，内容不含遮罩、提示、手柄或工具栏。依据是只裁剪冻结帧 `frame_.pixels`，显示层不参与裁剪；已知彩色像素也有自动回读验证。
- 中文 / 空格目录和文件名、缺后缀补 `.png`、同名覆盖确认、拒绝覆盖与取消均保留原文件及截图；补后缀后同名文件也需确认。
- 保存面板按 Esc 只关闭面板；焦点恢复后再按 Esc 才取消截图。保存失败可更换路径重试；成功可再次保存或复制。
- 预先准备剪贴板内容，分别执行 Esc、取消按钮、关闭覆盖层，确认剪贴板不变且未多出图片文件；主动保存后取消则原 PNG 保留。
