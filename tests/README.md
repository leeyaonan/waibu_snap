# 自动化测试

> 测试框架与运行方式待技术选型确定后，补充到本文件与工作区 `AGENTS.md` 第 6 节。

## 分层

| 目录 | 层次 | 关注点 |
| --- | --- | --- |
| `unit/` | 单元测试 | 纯逻辑：算法、工具函数、状态管理 |
| `integration/` | 集成测试 | 跨模块：IPC、剪贴板、文件 IO、系统交互 |
| `e2e/` | 端到端测试 | 真实应用流程：热键触发、截图、标注、导出 |
| `fixtures/` | 测试素材 | 多屏 / HiDPI 截图样本、模拟数据 |

## 约定

- 用例命名与注释使用中文。
- 素材命名体现场景，如 `hidpi-2x-dual-monitor.png`。
- 回归缺陷：先补一个能复现失败的用例，再修复。
- 平台相关用例需标注适用平台（mac / win / both）。
