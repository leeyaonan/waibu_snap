# 自动化测试

使用 Qt Test + CTest，Python 3 仅运行测量计算单测（标准库）。构建后执行成对的 `test-project` 脚本。

| CTest 名称 | 覆盖 |
| --- | --- |
| `startup_smoke` | 真正应用子进程加载动态库、进入事件循环，关闭临时窗口后仍驻留，再触发实际托盘「退出」；覆盖层首帧绘制、Retina 反向框选、松开保留、移动与夹取、四边 / 四角调整与光标、反向调整最小 1×1、外部单击清除 / 拖动替换；复制失败重试及成功码 10；保存失败重试、取消、补后缀冲突与原文件保护、面板期间 Esc / 拖选隔离、焦点恢复、面板期间关闭不导出；保存后继续复制 / 取消与 dirty 标记；取消按钮 / Esc / 关闭均不调用输出缝且临时目录和已有文件不变；受控参数需显式启用测试模式 |
| `selection_geometry` | 半开像素矩形、任意框选方向、屏内移动且尺寸不变、八方向调整、反向拖过对侧夹停、最小尺寸恢复、1.5 / 2 倍 DPR 与半像素边界取整、零面积与无效参数；未完成计时不能伪造可交互终点 |
| `image_output` | 冻结帧逐像素裁剪与 DPR=1；临时中文 / 空格路径 PNG 写出、格式 / 尺寸 / 全图像素回读一致；缺失目录与只读文件失败、原文件不变；无效图像 / 路径拒绝；补后缀与建议文件名冲突避让 |
| `probe_cpu_calibration`（macOS） | libproc Mach 时间换算对照 getrusage CPU 微秒时间；原错误在 M3 Pro 上先失败，修正后通过 |
| `measurement_tool` | nearest-rank 30 次第 29 项、最大样本和空样本；有效会话集合 `(1, 2, 10)`、旧码兼容与缺失终点过滤；刷新代理不能宣布通过；跨进程 CPU 总和、进程退出后的记账缺口 |

`startup_smoke` 使用 `QT_QPA_PLATFORM=offscreen`，验证 QWidget / 菜单动作与生命周期；无头环境不显示系统托盘，也不注册真实热键或申请屏幕录制权限。复制测试注入 `OverlayActions::copyImage`，仅验证动作次数、物理像素 / DPR 及终态，不读写或断言系统剪贴板。面板测试注入 `chooseSavePath`，路径导出调用真实 PNG 编码与原子提交，不能代替原生面板实机验收。

实际应用执行 `--smoke-test` 时检查驻留策略、菜单结构、临时窗口显示及关闭、事件循环持续运行，再触发「退出」动作；退出断言有进程超时与状态检查。`--smoke-test` 仅 `BUILD_TESTING=ON` 可用，不能把关闭最后窗口即退出当作托盘应用行为。普通截图不因松开而结束；NF01 受控注入仍可交互后自动取消（码 2）。

2026-10-02 本机 macOS / arm64、Qt 6.11.2 Release 构建、5 项 CTest 与 clang-format 18.1.8 检查通过。另运行真实应用受控模式 2 次：首条冷、第二条热，均具备 `visible_proxy_ns` / `interactive_ns`、选区尺寸为 0、终态码为 2，进程正常退出；只核对注入协议，不替代本轮 30 冷 + 30 热或外部呈现验收。

## 人工核对清单（待用户真机操作）

- macOS 从菜单栏或 F1 截图：移动、八个边角、反向夹停、屏边夹取、尺寸提示与工具栏位置。
- 点击「复制」后在支持图片的系统应用与日常沟通应用粘贴，核对内容与物理像素尺寸，确认会话结束。Qt 本地接受检查不能证明外部应用已正确粘贴。
- 保存 PNG 后用系统图片查看器打开，像素尺寸与工具栏提示一致，内容不含遮罩、提示、手柄或工具栏。依据是只裁剪冻结帧 `frame_.pixels`，显示层不参与裁剪；已知彩色像素也有自动回读验证。
- 中文 / 空格目录和文件名、缺后缀补 `.png`、同名覆盖确认、拒绝覆盖与取消均保留原文件及截图；补后缀后同名文件也需确认。
- 保存面板按 Esc 只关闭面板；焦点恢复后再按 Esc 才取消截图。保存失败可更换路径重试；成功可再次保存或复制。
- 预先准备剪贴板内容，分别执行 Esc、取消按钮、关闭覆盖层，确认剪贴板不变且未多出图片文件；主动保存后取消则原 PNG 保留。
- Windows 原生捕获仍为桩，本轮 CI 只证明共享代码编译与自动测试。Windows 11 真机、Intel Mac、混合 DPI / 负坐标屏幕、权限撤销、热插拔、真实呈现与本轮 NF01 / NF03 性能复测仍待验证，不据 offscreen 宣称通过。
