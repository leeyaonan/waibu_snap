# 图像与标注核心

实现半开物理像素选区归一化、保持尺寸的屏内移动、四边 / 四角调整与边界取整。调整越过对侧时夹停在对侧前 1 个物理像素，不翻转手柄；每次从按下快照计算，避免累积取整。

`annotation` 提供六类基础标注、颜色 / 线宽 / 字号预设、箭头几何和自由画笔点序列。坐标均为冻结帧绝对物理像素，裁剪窗口变化不修改标注。`AnnotationHistory` 支持最近 20 步撤销 / 重做，超限保留早期画面，撤销后新增清除重做分叉；会话结束清空，不持久化。不得依赖平台句柄或具体视图。

`history_types` 提供截图历史的分组、记录、策略、来源、排序、占用与名称校验；`history_cleanup` 根据单组快照选择候选，保护星标 / 最新 / 当前回放 / 超大项，外部图片不纳入清理。两者不依赖 QWidget 或文件系统；磁盘扫描与持久化由 `app/history_store` 负责，本批未接入截图输出。
